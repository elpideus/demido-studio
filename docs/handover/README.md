# Hand-over notes

One file for each piece of work done in a session of its own (DECISIONS, section W). The session that did
the piece writes it; the worker that reads and merges the piece folds what it says into `DECISIONS.md`,
`PLAN.md` and `IDEAS.md`, and the note then stays here as the record.

A note says, in this order and in plain words:

1. **What was asked**, in one or two lines.
2. **What is built**, with the files.
3. **What is not built**, and why. Nothing is left as a silent stub.
4. **Choices made that the brief and the decisions did not settle**, each with the other options and the
   reason. These are proposals: the reader may send them back.
5. **What was looked up**, each fact with its source and how sure it is: *Tried* (run on this computer),
   *Read* (in the source linked), *Search* (a search result, not read in full), *Memory* (not checked today).
6. **What was tried for real**, with what happened, and what was not tried.
7. **Ideas and doubts** raised on the way.
