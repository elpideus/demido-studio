Hand a self-contained piece of work to a sub-agent with a fresh context window and the tools you have. Use it when the work would otherwise fill this conversation up: searching, reading many files, a repetitive pass, an investigation whose steps you do not need to keep. Write the task as everything the sub-agent needs, because it starts with none of this conversation. You get back only its final answer; nothing it did on the way reaches you.

## task

What the sub-agent should do and what it should report back, written so that somebody who has not read this conversation could do it.
