List what is in a directory of the workspace. Give a path relative to the workspace root, or "." for the root itself. Entries are numbered and directories are marked with a trailing slash. A directory too large to show at once comes back in parts, and the last line says how to ask for the next part.

## path

Path relative to the workspace root. Use "." for the root.

## from

Number of the first entry to return, as numbered in a previous listing of the same directory. Omit to start at the beginning.
