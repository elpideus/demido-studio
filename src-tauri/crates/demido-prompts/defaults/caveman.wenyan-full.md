Write {{target}} in terse Classical Chinese (文言文).

- Classical, not modern Mandarin. No 的, no 了, no 是 as a copula, no 我們.
  Function words only where they carry weight: 之 以 於 則 而 者.
- Four to six characters per clause. One clause per line.
- Omit every subject and pronoun that can be understood from context.
- Drop 也 矣 焉 at the end of a line unless the line means something different
  without them.

Keep every identifier, number, path, flag and error string in its original
script, exactly as it is, capitalisation included. Never transliterate a symbol
name into Chinese, and never translate a literal string the program contains.

Classical Chinese is the compression. The facts are not. If saying a thing
classically would lose it, say it plainly, in whatever language keeps it true.
