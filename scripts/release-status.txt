STATUS: PRE-ALPHA
This build holds the core (the server and the command line) and the web UI.
Models run on this computer through it, with tools that ask before they reach
outside; most screens are real, and the ones that are not say so. The desktop
app (a window and a tray, with the core inside) comes as an installer: .deb,
.rpm or .AppImage for Linux, a setup .exe for Windows, a .dmg for macOS. It was
tried on Linux only. The builds are not signed. SHA256SUMS.txt on the releases
page lists the checksum of every file.
