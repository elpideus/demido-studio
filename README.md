# Demido Studio

An LLM harness that makes small models behave, and shows you why.

Windows first, cross-platform by 1.0. Local inference, tools that come integrated instead of
hand-assembled, and an append-only session log so nothing the model sees is hidden from you.

**Status: pre-alpha.** The foundation is being charted in the open. See the
[wayfinder map](../../issues?q=label%3Awayfinder%3Amap) for what is decided and what is still open,
and [`docs/brief.md`](docs/brief.md) for the canonical brief this project is built against.
