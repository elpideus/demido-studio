Why is Qwen3 so slow on my laptop?

The model is running partly on the CPU.

It needs 9.8 GB of VRAM. You have 7.6 GB free, so 11 of 33 layers run on the CPU.

  1. Open Models › Load settings.
  2. Set quantization to Q4_K_M (6.1 GB).
  3. Set context length to 8192 tokens.
  4. Select Reload. It takes about 12 s.

CAUTION Reloading pauses the 2 jobs that borrow this model. They resume when it is back.
